# 1. O QUE ESTE SITE PRECISA FAZER

O site é a casa institucional da marca Ju Ferreira.

Ele deve:

- organizar um universo amplo sem reduzi-lo a uma persona;
- permitir que pessoas diferentes entrem por portas diferentes;
- construir autoridade intelectual;
- demonstrar lastro real;
- sustentar conversão B2B e B2C;
- preservar clareza entre tese, produto, projeto, história e oferta;
- tornar visível a relação entre futuros, tecnologia, humanidade, estratégia e transformação;
- mostrar que Ju pensa, vive, testa e constrói no mundo real;
- preparar o ecossistema para crescimento futuro sem fingir que ofertas ainda inexistentes já estão prontas.

O site não deve parecer:

- site de coach;
- site de palestrante genérico;
- portfólio de futurista-gadget;
- consultoria de tendências;
- hub de inteligência artificial;
- autobiografia;
- catálogo de empresas;
- infoproduto;
- revista puramente editorial;
- página institucional fria.

A síntese é:

> **uma casa autoral, estratégica e comercial para um pensamento que atravessa futuros, tecnologia, humanidade, transformação e construção no mundo real.**

# 3. A ESPIRAL

Arquitetura de movimento:

> **IMAGINAR → ESCOLHER → TORNAR-SE → CONSTRUIR ↻**

Não é:

- funil;
- checklist;
- jornada linear;
- “quatro passos para mudar sua vida”;
- método fechado;
- modelo psicométrico.

É uma espiral.

Significados:

**Imaginar**  
Abrir possibilidades.

**Escolher**  
Dar direção.

**Tornar-se**  
Desenvolver capacidades.

**Construir**  
Colocar alguma coisa no mundo.

Depois, a realidade responde.

A pessoa ou organização volta à pergunta em outro lugar.

Frase estrutural:

> **Nós construímos futuros e somos construídos enquanto os construímos.**

Regra de realidade:

> **A Espiral precisa caber numa terça-feira qualquer.**

# 4. FUTURISMO HUMANISTA

Futurismo Humanista não é “futurismo com mais emoção”.

É a lente pela qual Ju investiga futuros por causa das pessoas, das escolhas, das capacidades e das consequências.

Não é:

- fetiche tecnológico;
- previsão;
- tendência por tendência;
- estética futurista;
- distopia ou utopia como performance.

Princípio:

> **Rigor no subsolo. Clareza no palco.**

# 18. SISTEMA VISUAL — PRINCÍPIOS

- preto/grafite em off-white;

- vinho profundo em aplicações específicas;

## Paleta

Direção já consolidada nos mockups:

- off-white quente;
- quase-preto / grafite;
- vinho profundo;
- vermelho como gesto / anotação / energia visual;
- rosa pálido como suporte editorial.

Evitar:

- neon;
- estética sci-fi;
- azul tecnológico genérico;
- gradientes futuristas;
- excesso de roxo legado como cor principal.

Sistema editorial:

- serif de alto contraste para headlines;
- sans limpa para corpo e interface;
- manuscrita para anotações, nunca para grandes blocos de leitura.

## Espiral

Símbolo secundário / linguagem gráfica.

Deve parecer:

- humana;
- imperfeita;
- orgânica;
- em movimento.

Não:

- geométrica demais;
- perfeita demais;
- “logo tech”;
- símbolo oficial substituto.

## Fotografia

- cidade futurista;
